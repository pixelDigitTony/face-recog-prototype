# MediaPipe Face Landmarker bundle

Package: `@mediapipe/tasks-vision` 1.2.0, Apache-2.0.
The accompanying Apache license text is in `mediapipe.txt`.

Model bundle revision: `face_landmarker/float16/1`.
Source and SHA-256 are pinned in `models/liveness-manifest.json`.
The bundle contains face detection, Face Mesh V2 and blendshape models.
Upstream model cards identify Apache License 2.0:

- [Face detector](https://storage.googleapis.com/mediapipe-assets/MediaPipe%20BlazeFace%20Model%20Card%20(Short%20Range).pdf)
- [Face Mesh V2](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20MediaPipe%20Face%20Mesh%20V2.pdf)
- [Blendshapes](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Blendshape%20V2.pdf)

Landmark/pose inference is used for an experimental motion challenge. These models do not supply a validated presentation attack detection verdict. Preserve upstream notices when redistributing.
